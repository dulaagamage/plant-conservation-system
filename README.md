# 🌿 Smart Herbal Plant Management System

A modern web-based medicinal plant conservation and management platform developed using Laravel and Tailwind CSS.

This system was designed to digitally manage medicinal plant records, support biodiversity conservation efforts, and connect physical herbal gardens with interactive QR-powered botanical information pages.

---

# ✨ Features

## 🌱 Public Botanical Library
- Browse medicinal plant collection
- Search plants by name or scientific name
- Responsive botanical-themed UI
- QR-connected plant profile pages

## 📖 Detailed Plant Profiles
Each plant contains:
- Scientific classification
- Medicinal uses
- Botanical description
- Conservation status
- Ayurveda / Hela-Veda applications
- Ecological importance
- Research information
- Habitat details
- Associated wildlife
- Garden zone information

## 🔐 Admin Dashboard
Authenticated administrators can:
- Add plants
- Edit plant records
- Delete plants
- Manage biodiversity data
- Maintain QR-linked botanical entries

## 🎨 Modern UI/UX
- Tailwind CSS interface
- Botanical animations and patterns
- Responsive design
- Glassmorphism-inspired components
- Interactive cards and transitions

# 🚀 Installation

## Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

## Navigate to Project

```bash
cd plant-system
```

## Install Dependencies

```bash
composer install

npm install
```

## Configure Environment

Create `.env` file and configure database credentials.

## Generate App Key

```bash
php artisan key:generate
```

## Run Migrations

```bash
php artisan migrate
```

## Seed Database

```bash
php artisan db:seed --class=PlantSeeder
```

## Start Development Server

```bash
php artisan serve
```

Run Vite:

```bash
npm run dev
```
